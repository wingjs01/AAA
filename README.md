# 單字吊人（Hangman Vocabulary）

> 要把這套系統整合進其他專案？看 [HANDOFF.md](HANDOFF.md)。

英文背單字 × 吊人遊戲。看中文意思與音標，把英文單字拼出來；每拼錯一次，絞刑架上的人就多長出一塊，錯滿 6 次人被吊死，**整局通關失敗**。

## 玩法

1. 選難度（簡單 / 中等 / 困難），每局 5 關，一關一個單字。
2. 題目只給 **中文意思 + 音標 + 字母數**，按 🔊 可以聽發音。
3. 用實體鍵盤或畫面上的字母按鈕猜字母：
   - 猜中 → 該字母的所有位置一次翻開。
   - 猜錯 → 吊人多畫一塊（頭 → 身 → 左手 → 右手 → 左腳 → 右腳）。
4. 錯滿 6 次 → 被吊死，遊戲結束並顯示答案與複習清單。
5. 拼完 5 關 → 全部通關。

## 輔助

| 功能 | 說明 |
| --- | --- |
| 💡 提示 | 隨機揭開一個還沒猜到的字母，**代價是一次錯誤機會** |
| 📖 例句 | 顯示含該單字的例句（困難模式停用） |
| 🔊 發音 | 用瀏覽器語音合成朗讀單字（`en-US`） |

## 自建字庫

首頁「我的字庫」→ **＋ 新增字庫**，就能建立自己的單字表。

**你只要打英文單字，音標和發音是自動的。** 遊戲內建 CMU 發音辭典（117,449 個英文單字），
打完單字約 0.3 秒後音標就會自己填進去，不需要連網、不需要 API 金鑰。查不到的字（例如自創字、
少見專有名詞）音標會留空，但 🔊 發音仍然可用。

| 欄位 | 必填 | 說明 |
| --- | --- | --- |
| 英文單字 | ✅ | 只接受英文字母、空白、連字號、撇號；至少兩個字母。片語（如 `ice cream`）可以，空白會自動顯示不用猜 |
| 中文意思 | — | 留空也可以。題目會自動切成**「聽發音拼單字」**模式：放大的 🔊 按鈕、自動念一次、音標加字母數當線索 |
| 音標 | 自動 | 系統自動填入，也可以自己改；改過之後就不會被覆蓋 |
| 例句 | — | 單字的位置寫 `___`；直接把單字寫進句子裡也行，遊戲會自動遮起來 |

其他操作：

- 清單每一列可以 🔊 試聽、✎ 修改、🗑 刪除。
- 一個字庫一局最多 5 關，單字不足 5 個就有幾個玩幾關。
- **⬇ 匯出備份 / ⬆ 還原備份**：字庫存在瀏覽器的 localStorage，清除瀏覽資料會一起消失。
  手動輸入很多單字之後建議匯出一份 JSON 留底；還原時重複的單字會自動略過。

> 注意：字庫存在「這台裝置的這個瀏覽器」裡，不會跨裝置同步，無痕視窗也存不住。

## 用 LINE 上傳單字

除了在網頁上逐筆輸入，也可以透過 LINE bot 建題庫：

- 在 LINE 打字傳單字（`apple 蘋果`，一行一個），或**直接拍課本照片**
- 照片由 Claude 視覺辨識出「英文 ↔ 中文」配對，自動補音標後存入題庫
- 以 **LINE 帳號**識別，底下可分多個題庫（課本第一課、社團第一課…）
- 遊戲首頁會多出「LINE 題庫」區塊，直接開局

這部分需要自行部署後端（Cloudflare Workers + D1），
完整步驟見 [`server/README.md`](server/README.md)。

沒有部署也完全不影響——把 `config.js` 的 `API_BASE` 留空，
遊戲就只使用內建字庫與瀏覽器本機字庫，行為跟原本一模一樣。

## 音標是怎麼來的

`ipa/` 目錄是把 [CMU Pronouncing Dictionary](https://github.com/cmusphinx/cmudict) 的 ARPAbet 音標
轉成 IPA 的成果，依首字母切成 26 個檔案，查哪個字母才載入哪一份（平均約 80KB），所以開場很快。

轉換規則包含長音符號（`ɔː`/`uː`/`iː`）、音節切分（最大起始原則）、主重音與次重音，
並套用兩條英語慣例：單音節字不標重音、重音短母音必須閉音節（`ˈæp.əl` 而非 `ˈæ.pəl`）。
拿內建 45 個手寫音標當測試集，71% 完全一致，其餘差異都是 `ə`/`ɪ` 這類合法的替代標法。

## 計分

- 過關基礎 100 分，每錯一次 −15，每次提示 −25，最低 20 分。
- 零失誤（沒猜錯也沒用提示）額外 +30。

## 執行

不需要安裝任何東西，直接用瀏覽器開啟 `index.html` 即可。

```bash
# 或起一個本機伺服器
python3 -m http.server 8000
# 然後開 http://localhost:8000
```

## 改內建字庫

自建字庫用網頁介面就好；要改**內建**的三個難度，編輯 `words.js`，在對應難度的陣列裡加一筆：

```js
{ word: 'library', zh: '圖書館', ipa: '/ˈlaɪ.brer.i/', hint: 'She borrowed three books from the ___.' }
```

`word` 請用全小寫英文字母，`hint` 裡的單字用 `___` 取代。
